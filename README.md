
# Text Validator LLM

Simple API to validate text using a large language model (LLM). 
This API allows to send text input and receive validation results based on defined criteria.
Built with NestJS and TypeScript.

## Getting started
- Local development: `npm run start:dev`

## NestJS cli
- Works like Angular CLI - use for adding modules, controllers, services, etc.
- Typical sequence:
    - `nest g module <module-name>` - generates a new module
    - `nest g controller <controller-name>` - generates a new controller
    - `nest g service <service-name>` - generates a new service
